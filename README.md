# 🎵 Remix Studio

A web-based music remix app by Nahi.

## Features
- Add MP3/WAV songs
- Bass, Remix & Sound effects (hold to apply)
- Timeline with draggable effect blocks
- Custom effects & sounds
- Loop, Undo/Redo, Save/Load, Export
- Works on mobile & desktop

## How to Use
1. Open `index.html` in browser
2. Add a song
3. Hold effect buttons to apply
4. Add blocks on timeline for timed effects
5. Export your remix!
